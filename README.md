# HR Analytics Dashboard | Power BI

Project Overview
This project explores HR data using Power BI to understand workforce
composition, employee attrition, employee experience, hiring and
termination patterns, and salary information.

I created an interactive dashboard to turn employee-level data into
clear visual summaries that are easier to explore and understand.

## Project Objectives
Understand the size and composition of the workforce.
Compare current employees with employees who have left the company.
Calculate and review the attrition rate.
Explore employee distribution by department, gender, and education.
Review job satisfaction and work-life balance.
Explore hiring and termination patterns over time.
Summarize salary data and explore salary patterns.

# Tools Used
Power BI --- dashboard creation and data visualization
Power Query --- data preparation and cleaning
DAX --- measures and calculations

# Interactivity
The dashboard includes slicers such as department, job role, gender, and
date filters where configured. These controls help users explore subsets
of the employee data.
